# 대화형 EQ와 기기별 튜닝 방향

2026년 9월 30일 사용자 요청을 기록한다. OpenAI API와 Dots 연결은 보관할 구상이며, 현재 구현 범위는 MCP의 기본 보정과 취향 튜닝 저장 흐름이다.

## 보관할 아이디어

Auralink 앱 안에서 “보컬을 앞으로, 치찰음은 줄여줘” 같은 자연어 요청으로 EQ를 직접 조절한다. OpenAI API의 도구 호출을 앱의 기존 검증·적용·되돌리기 기능에 연결하는 방향이다. 오디오 처리는 Mac에서 수행하고, 모델에는 현재 설정·기기 보정 정보·사용자 요청·피드백을 전달한다. 기본적인 설정 조절에는 오디오 업로드가 필요하지 않다.

앱 내부 대화와 Dots 등 외부 에이전트가 같은 EQ 제어 기능을 사용하도록 설계한다. 외부 경로에는 기존 MCP를 활용한다. Dots의 연결된 컴퓨터·플러그인 지원은 공식 문서에서 확인했으나, Auralink MCP와의 실제 호환성은 아직 검증하지 않았다. 사용자 API 키 저장 방식과 배포용 인증·과금은 추후 결정한다.

참고: [OpenAI 도구 호출](https://developers.openai.com/api/docs/guides/function-calling), [Dots 컴퓨터와 앱 연결](https://learn.chatgpt.com/docs/dots/computers-and-apps).

## 이번에 확정한 사용자 요구

- 헤드폰·이어폰을 처음 등록하면 기본 보정 프리셋을 자동 저장한다.
- 기본 보정에서 출발해 취향에 맞는 튜닝을 만들고 별도 프리셋으로 자동 저장한다. 저장 여부를 매번 따로 묻지 않는다.
- 사용자가 MCP를 통해 불필요한 튜닝을 삭제할 수 있어야 한다.

이 요구는 종전의 “임시 청음 후 마음에 들 때만 저장” 정책을 변경한다. 자동 저장은 사용자가 좋아했다는 의미가 아니며, 실제 반응만 취향 기록으로 남긴다.

## 구현 해석

여기서 플랫은 기기의 측정 자료와 명시된 타깃에 따른 기본 보정으로 해석했다. 모든 밴드를 0으로 둔 바이패스와 구별하며, 사용자의 귀에서 완전한 평탄 응답을 보장한다는 뜻은 아니다. 자료가 없으면 정확한 측정 보정을 만들어내지 않고, 출처와 신뢰도가 명시된 보정값을 받는다.

기본 보정은 취향 변경으로 덮어쓰지 않는다. 저장과 실제 재생 적용은 구분하고, 앱의 읽기 전용 등 기존 권한 설정을 존중한다. 키체인 잠금 해제와 배포 서명 작업은 사용자 요청대로 나중에 진행한다.
